1 使用说明与安全要求

1.1 手册用途

本手册面向使用 YONIQ AXIS 电机控制器的系统集成工程师、运动控制工程师和调试人员，说明如何通过 CANopen 或 EtherCAT 完成设备识别、参数访问、CiA 402 状态切换、PDO 周期控制、运动模式配置和故障诊断。

CANopen 和 EtherCAT 使用同一套 CiA 402 驱动器对象。两种总线的区别主要在于通信管理、过程数据传输和同步方式：CANopen 使用 NMT、SDO、PDO 和 SYNC；EtherCAT 使用 ESM、CoE、Sync Manager、PDO 和 Distributed Clocks。

1.2 使用前准备

开始通信调试前，应完成以下检查：

  • 电机、电源、编码器和急停回路连接正确。
  • 控制器固件与所使用的通信接口一致。
  • CANopen 主站已导入 YONIQ_AXIS.eds；
  • EtherCAT 主站已导入 Yoniq_EtherCAT_Slave.xml。
  • 首次上电时目标位置、目标速度和目标转矩均为零。
  • 首次运动采用空载、低速和限流条件。
  • 上位机控制与总线控制不能同时占用驱动器；使用总线控制前应将控制权限切换至总线侧。

1.3 安全提示

通信建立成功只表示主站能够访问驱动器，不代表电机具备安全运行条件。执行 0x6040=0x000F 前，应确认模式、目标值、方向、限位和电流限制均正确。

位置模式首次使能前，建议先读取 0x6064，并将目标位置设置为当前实际位置。速度和转矩模式首次使能前，应将 0x60FF 和 0x6071 设置为零。

发生过流、编码器、母线电压、过温或位置跟随误差故障时，应先排除故障原因，再执行 Fault Reset。禁止连续发送复位命令掩盖真实故障。

2 系统概述与快速开始

2.1 通信接口

YONIQ AXIS 提供 CANopen 和 EtherCAT 两种通信方式。CANopen 适用于基于 CAN 的多轴控制和参数配置；EtherCAT 适用于高刷新率过程数据和分布式时钟同步控制。

两种总线均通过 CiA 402 对象控制驱动器。主站可通过对象 0x6040 控制状态机，通过 0x6041 获取状态，通过 0x6060 选择运行模式，并使用对应目标对象下发位置、速度或转矩。

2.3 CANopen 快速开始

1. 连接 CANH、CANL 和 GND，在总线两端安装终端电阻。

2. 将主站波特率设置为设备波特率。默认配置为 1 Mbit/s。

3. 设置唯一的 Node-ID。默认配置为 0x15，允许范围为 1～127。

4. 导入 YONIQ_AXIS.eds，等待设备发送 Boot-up。

5. 发送 NMT Start Remote Node，使节点进入 Operational。

6. 读取 0x603F、0x6041、0x6061 和 0x6502。

7. 选择模式并写入安全目标值。

8. 按 0x0006、0x0007、0x000F 顺序使能。

2.4 EtherCAT 快速开始

1. 将 ESI 文件复制到主站对应的 EtherCAT 设备描述目录。

2. 重新扫描设备目录并扫描 EtherCAT 网络。

3. 核对设备标识和 PDO。

4. 使从站依次进入 INIT、PREOP、SAFEOP 和 OP。

5. 在 PREOP 使用 CoE 读取 0x603F、0x6041、0x6061 和 0x6502。

6. 根据运动模式选择或连接对应 PDO。

7. 周期同步模式应配置 SM-Synchron 或 DC-Synchron。

8. 进入 OP 后按 CiA 402 顺序使能。

3 CiA 402 驱动器状态机

3.1 状态机概述

CiA 402 的 PDS FSA 用于管理功率输出和运动功能。总线已进入正常通信状态后，驱动器仍不会自动输出电流，主站必须通过控制字完成状态切换。

典型使能路径如下：

Switch on disabled → Ready to switch on → Switched on → Operation enabled

3.4 标准使能流程

1. 读取 0x6041，确认 bit3 为 0。

2. 写 0x6040=0x0006，等待状态变为 Ready to switch on。

3. 写 0x6040=0x0007，等待状态变为 Switched on。

4. 写 0x6040=0x000F，等待状态变为 Operation enabled。

5. 运行中持续监视 0x6041、0x603F 和实际值。

6. 停止时先降低目标值，再根据应用发送 Disable operation 或 Disable voltage。

3.5 快速停止与暂停

Quick stop 命令由 0x6040 bit2 控制，减速度由 0x6085 配置，最终状态还受 0x605A Quick stop option code 影响。驱动器在完成快速停止后进入 Quick stop active 或关闭输出。

Halt 使用 0x6040 bit8。Halt 用于暂停轮廓运动，不等同于急停。安全相关停止应使用硬件急停和驱动保护，不应只依赖 Halt。

4 CANopen 通信协议

4.1 接线与网络配置

CAN 总线采用线型拓扑。CANH、CANL 和参考地应可靠连接，总线两端安装 120 Ω 终端电阻，支线应尽量短。

默认 Node-ID 为 0x15，允许范围为 1～127。默认波特率为 1 Mbit/s。修改节点 ID 或波特率后，应保存配置并重新启动设备。

4.5 Heartbeat

0x1017 为 Producer heartbeat time，单位 ms。设备按该周期发送 Heartbeat。主站应设置大于生产周期的超时值，并预留总线负载和任务调度裕量。

Heartbeat 数据字节表示 NMT 状态：0 为 Boot-up，4 为 Stopped，5 为 Operational，127 为 Pre-operational。

当主站检测到 Heartbeat 超时，应停止向该节点发送运动目标，并执行系统级安全处理。

4.6 EMCY

设备故障时可通过 EMCY 报文通知主站。主站收到 EMCY 后，应同时读取 0x603F、0x1001、0x1003 和 0x6041，确定故障类别和当前 CiA 402 状态。

4.8 PDO 重映射步骤

以 RPDO1 为例：

1. 将 0x1400:01 的有效位设置为禁用。

2. 写 0x1600:00=0，清空映射数量。

3. 从 0x1600:01 开始写入映射项。映射值格式为 Index<<16 | SubIndex<<8 | BitLength。

4. 写 0x1600:00 为实际映射数量。

5. 配置 0x1400:02 传输类型。

6. 重新启用 0x1400:01。

7. 进入 Operational 后验证 PDO 内容。

单个 CAN PDO 最大为 8 byte，映射总长度不得超过 64 bit。映射方向必须正确：主站写入对象放入 RPDO，从站反馈对象放入 TPDO。

4.9 SYNC 和周期 PDO

同步 PDO 由 COB-ID 0x080 的 SYNC 报文触发。周期同步模式使用 CANopen 时，应先确定主站 SYNC 周期，再配置 PDO 传输类型。目标 PDO 必须在规定周期内更新；主站停止 SYNC 时应执行安全策略。

4.10 三环增益调节与参数保存

通过 SDO 可读取和设置电流环、速度环及位置环增益，参数地址和数值换算见附录 A.7。需要断电保留时，按附录 A.8 执行保存。主站应导入与设备配套的 YONIQ_AXIS.eds，并将节点置于 Pre-operational 或 Operational 状态；调参和保存均使用单子索引 SDO，不使用 PDO。

5 EtherCAT 通信协议

5.1 EtherCAT 系统组成

EtherCAT 网络由一个主站和一个或多个从站组成。主站周期发送 EtherCAT 帧，从站在帧经过时读取输出数据并写入输入数据。

从站使用 ESI 文件向主站描述设备标识、对象字典、邮箱、Sync Manager、PDO 和 Distributed Clocks 配置。主站配置必须与设备当前 ESI 版本一致。

5.4 邮箱与 CoE

当前邮箱输出和输入默认大小均为 0x80 byte。CoE 支持 SDO 信息、PDO Assign、PDO Config、Complete Access 和 Segmented SDO。具体对象仍受访问属性限制；0x60F6、0x60F9、0x60FB 和 0x1010 不支持 Complete Access，须按单子索引访问。

CoE 的索引、子索引和数据类型与 CANopen 对象字典一致，但传输封装由 EtherCAT 邮箱完成，不使用 CANopen 的 0x600/0x580 COB-ID。

参数配置建议在 PREOP 完成。OP 状态下可读取诊断对象，但高频目标值应使用 PDO。

5.8 PDO Assign 和重映射

0x1C12 用于 SM2 RxPDO Assign，0x1C13 用于 SM3 TxPDO Assign。0x1600～0x1603 为 RxPDO Mapping，0x1A00～0x1A03 为 TxPDO Mapping。

重映射流程：

1. 从站进入 PREOP。

2. 将 0x1C12:00 或 0x1C13:00 写为 0。

3. 将目标映射对象的 subindex 0 写为 0。

4. 依次写入映射项。

5. 写入实际映射数量。

6. 将 PDO 索引写入 0x1C12 或 0x1C13。

7. 写入 Assign 数量。

8. 重新进入 SAFEOP，检查 SM 长度和 AL Status。

9. 进入 OP，逐项验证过程数据。

映射对象不存在、方向错误、位宽错误或总长度与 Sync Manager 不一致时，从站可能停留在 SAFEOP 或报告 Invalid Sync Manager Configuration。

5.9 SM-Synchron 与 DC-Synchron

设备提供 SM-Synchron 和 DC-Synchron 两种同步方式。

SM-Synchron 由输出 Sync Manager 事件驱动应用数据更新，适合不使用分布式时钟的场景。

DC-Synchron 使用 Sync0 作为参考事件。ESI 的 DC 模式 AssignActivate 为 0x0300。周期同步位置、速度和转矩控制建议采用 DC-Synchron，并使主站任务周期、Sync0 周期和目标值更新时间一致。

本手册不规定唯一最小周期。首次调试可从 1 ms 或更慢周期开始，并同时观察 WKC、AL 状态、0x6041、实际值和跟随误差。只有连续运行稳定后才可缩短周期。

5.10 EtherCAT Watchdog 与掉线

主站停止发送过程数据、网线断开、WKC 异常或 Sync0 丢失时，从站可能退出 OP 或进入同步错误。系统应保证：

  • 输出数据停止更新时电机进入安全状态。
  • 主站恢复后先读取错误和状态，不自动恢复运动目标。
  • 重新进入 OP 后重新执行 CiA 402 使能顺序。
  • 旧目标位置、速度和转矩在重新使能前被刷新为安全值。

5.11 当前 EtherCAT 功能范围

当前版本提供 EtherCAT ESM、CoE/SDO、PDO、SM-Synchron、DC-Synchron 和 CiA 402 运动控制。

当前版本不提供通过 EtherCAT 下载固件的用户功能。BOOTSTRAP/FoE 不应作为固件升级入口。EoE 网络功能不属于本手册规定的产品功能。

10 CSP CSV CST 周期同步模式

10.1 共同要求

周期同步模式由主站生成轨迹。目标值必须按固定周期更新，主站周期、通信周期和驱动器同步事件应保持一致。

0x60C2:01 为插值时间值，0x60C2:02 为时间指数。默认可读取为 1 和 -3，对应 1 ms；主站应读取实际值后再配置任务周期。

10.2 CSP

CSP 使用 0x607A 目标位置，单位 P；0x60B0 为位置偏置，单位 P。0x6064 返回实际位置。目标变化应连续，避免单周期大幅跳变。

10.3 CSV

CSV 使用 0x60FF 目标速度，单位 P/s；0x60B1 为速度偏置，单位 P/s。0x606C 返回实际速度。

10.4 CST

CST 使用 0x6071 目标转矩，单位 0.1 %；0x60B2 为转矩偏置，单位 0.1 %。0x6077 返回实际转矩。

10.5 通信中断处理

主站停止周期目标后，驱动器不应继续执行不可控的旧轨迹。系统调试必须验证 EtherCAT Watchdog、CANopen SYNC 丢失和主站任务停止时的安全行为。

12 EtherCAT 主站配置示例

12.1 导入 ESI

以 TwinCAT 3 为例，将 Yoniq_EtherCAT_Slave.xml 放入 TwinCAT EtherCAT ESI 目录，执行 Reload Device Descriptions，然后重新扫描设备。

12.2 扫描从站

1. 选择用于 EtherCAT 的网卡。

2. 扫描 EtherCAT devices。

3. 核对 Vendor ID、Product Code 和 Revision。

4. 检查从站端口 Link 状态。

5. 检查 Process Data 页面中的 SM2=20 byte、SM3=44 byte。

12.3 配置 PDO

使用默认 PDO 时，按第 5.6 和 5.7 节链接变量。修改 PDO 时，应在 PREOP 编辑 PDO Content，并检查 Startup 列表是否生成了 0x1C12、0x1C13 和映射对象写入。

12.4 配置 DC

在 DC 页面选择 DC-Synchron，设置 Sync0 周期与 PLC/NC 任务周期一致。首次建议使用 1 ms 或更慢周期。激活配置后检查从站能否稳定进入 OP。

12.5 轴使能

通过 PDO 或 CoE 依次写入 0x0006、0x0007、0x000F，并读取 0x6041 确认。不要只依赖主站软件的 Enable 按钮，应同时监视实际控制字和状态字。

13 故障诊断与恢复

13.1 通用诊断顺序

1. 检查总线物理连接和主站状态。

2. 检查 CANopen NMT 或 EtherCAT ESM。

3. 读取 0x6041 判断驱动器状态。

4. 读取 0x603F、0x1001 和 0x1003。

5. 读取 0x6061 确认模式。

6. 核对目标对象、PDO 布局、数据类型和单位。

7. 检查编码器、电流、母线电压和温度。

8. 排除故障后产生 Fault Reset 上升沿。

9. 重新执行完整使能顺序。

13.3 EtherCAT 无法进入 OP

按以下顺序检查：

  • ESI 与设备 Revision 是否一致。
  • SM2 和 SM3 长度是否与 PDO 总长度一致。
  • 0x1C12、0x1C13 是否包含有效 PDO。
  • 映射对象位宽和方向是否正确。
  • DC/Sync0 周期是否有效。
  • 主站 Working Counter 是否达到期望值。
  • AL Status Code 是否报告 Sync Manager、Watchdog 或 DC 错误。

13.4 目标值不生效

检查 0x6061 是否为期望模式，0x6041 是否为 Operation enabled，控制权限是否属于总线，目标对象是否连接到正确 PDO。PP 模式还应检查 bit4 上升沿。

13.5 Fault Reset 无效

如果 0x603F 仍为非零，说明故障条件尚未消除。检查电流、母线、编码器、温度、跟随误差和限位。故障清除后发送 bit7 上升沿，再将 bit7 清零。

14 通信与运动验收

14.1 CANopen 验收

  • 识别 Boot-up 和正确 Node-ID。
  • NMT 状态切换正常。
  • SDO 8/16/32 bit 读写正常。
  • Heartbeat 超时能被主站识别。
  • 默认 RPDO 布局与 MIT 对象一致。
  • PDO 重映射后收发数据正确。
  • SYNC 周期控制稳定。

14.2 EtherCAT 验收

  • 扫描信息与 ESI 一致。
  • INIT、PREOP、SAFEOP、OP 正常切换。
  • CoE 读写和 Abort Code 正确。
  • SM2=20 byte、SM3=44 byte。
  • 默认 PDO 偏移和值正确。
  • SM-Synchron 和 DC-Synchron 分别测试。
  • WKC 长时间稳定。
  • 断网、主站停止和重新连接时输出安全。
  • EEPROM 配置掉电后保持。

14.3 运动模式验收

对 PP、PV、PT、HM、CSP、CSV、CST 和 MIT 分别记录：

  • 模式设置与 0x6061 反馈。
  • 使能时间和状态字。
  • 目标与实际值。
  • 正负方向。
  • 限幅和保护。
  • 正常停止、Halt、Quick stop。
  • 通信中断行为。
  • Fault Reset 和重新使能。

14.4 调参与保存确认

1. 通过所用总线的 SDO 读取待调整的增益，按附录 A.7 换算，并记录原值。

2. 选择要修改的参数地址，将目标值按附录 A.7 换算为整数后写入。再次读取同一地址，确认读回值与写入值一致。

3. 以低速、限流条件进行试运行，观察运动响应。需要继续调整时，小幅修改参数并重复读回确认。

4. 调参完成后停止运动并退出电机使能，向 0x1010:01 写入 0x65766173，等待 SDO 下载成功。

5. 断电重启，再次读取已调整的参数，确认与保存前一致。未执行保存的修改在断电后不保留。

6. 若参数与预期不符，检查写入地址、缩放倍数及保存响应。如有 Abort，按 13.2 排查后重新设置和保存。

A.8 Flash 参数保存对象

需要断电保留调好的参数时，向 0x1010:01 写入保存指令 0x65766173（ASCII save）。CANopen 和 EtherCAT 使用相同的指令。此对象通过 SDO 访问，不使用 PDO。

该指令保存当前增益及设备配置。重新上电后，设备使用最近一次成功保存的参数。请使用 0x1010:01 保存；0x1010:02/03 分组保存和 0x1011 恢复默认设置不支持。

保存前，请停止运动、退出电机使能，并将控制权切换至总线。设备正在保存或处理其他存储操作时，请等待其完成后再操作；不要同时从两条总线发起保存。保存期间保持参数不变。

发出保存指令后，等待 SDO 下载成功响应。0x1010:01 的读取值为 1，表示支持命令保存，不表示保存进度。若返回 0x06060000，请停止重复保存，按 13.2 检查存储错误或频繁保存保护。

保存完成前请保持供电。若保存失败、超时或中途断电，不要认为本次修改已保留；恢复正常通信后，重新设置所需参数并保存，随后按 14.4 检查断电保持结果。CANopen 报文示例见 4.10，EtherCAT 操作示例见 5.12。

附录 C 当前产品功能说明

  • 当前产品不提供制动器输出控制功能。
  • 当前产品不提供用户通用 ADC、DI、DO 和运行指示灯接口。

  • 支持通过 CANopen SDO / EtherCAT CoE 读取和设置电流环、速度环及位置环增益，并通过 0x1010:01 保存，供下次上电使用。可设置的参数及操作方法见 4.10、5.12 和附录 A.7、A.8。
