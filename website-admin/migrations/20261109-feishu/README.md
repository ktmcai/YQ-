## 重新生成页面

在本目录运行 `npm install` 和 `npm run build`。这只生成首次导入用的 `网页/guides/*/content.html` 和 `catalog.json`，不会连接服务器，也不会覆盖后台已编辑的正文。首次导入附件位于 `网页/guides/<slug>/图片和附件/`。运行时网站无需 Node.js 或前端构建。

正式正文保存在 `/var/lib/yoniq-docs/documents.sqlite` 的 `guides` 表；图片和附件在同目录的 `guide-files/`，Nginx 将 `/guides/` 转发给后台。备份必须同时包含数据库、`files/` 和 `guide-files/`。`website-admin/import_guides.py` 只做带标记的一次性导入，重复运行不会覆盖已编辑内容。后台代码和静态站点重新部署不能替换这些持久化数据。
